# Vidmark 1.4.1

- Shows the saved AI provider and model in the sidebar; click it to open Settings.
- Consolidates provider and model preferences in Settings and removes the Build tab. Start builds from the course overview.
- Detects signed-in Codex and Claude Code CLIs and supports automatic model selection without a hard-coded model catalog.
- Adds read-only question fact-checking with evidence and visible review status.
- Supports reading-based courses, course-specific exams, and optional chapter videos.
- Protects course edits and transcripts from stale or cancelled agent writes, and preserves complete question banks and review history when sharing.
- Adds local debug controls and improves agent cancellation, research validation, and preference saving.
