# Vidmark 1.4.3

- Renders Markdown in chapter lessons and generated study guides, including clickable citations, headings, lists, code blocks, and tables.
- Styles course content for light and dark themes, with scrollable wide tables and code blocks.
- Keeps shared content safe: raw HTML and non-web links are blocked, and remote images open only when clicked.
- Preserves saved course content, notes, and provider preferences.
