# Vidmark 1.3.1

- Requires authentication before opening local study data or starting Vidmark's local services.
- Supports Touch ID or the Mac login password through Apple Local Authentication.
- Supports a six-digit app PIN stored as a salted, one-way local verifier.
- Adds manual locking, security settings, and automatic locking when the Mac sleeps or the user session locks.
- Requires Mac authentication to recover from incomplete or invalid saved security state.
